PetBites Cinematic Forest Update

Patch ini hanya mengubah src/styles.css.
Fitur translate EN/ID dan fitur lain tetap aman.

Cara pasang:
1. Extract zip.
2. Robocopy ke project:
   robocopy "D:\data C\Download\petbites_cinematic_forest" "D:\data C\Download\petbites" /E /R:1 /W:1
3. Hentikan server dengan Ctrl + C.
4. Jalankan npm run dev.
5. Hard refresh browser dengan Ctrl + F5.
