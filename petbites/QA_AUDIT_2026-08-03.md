# Audit QA PetBites

Tanggal audit: 3 Agustus 2026

## Kesimpulan

Source dashboard pengguna dan CMS admin sudah diaudit dan diperbaiki pada alur utama. Pemeriksaan statis, render server dengan data tiruan, serta mock operasi Supabase lulus. Audit ini tidak dapat menjamin aplikasi 100% bebas bug karena koneksi ke project Supabase produksi, akun admin asli, RLS yang sudah terpasang, Storage, dan Edge Function live tidak tersedia di sandbox.

## Perbaikan dashboard pengguna

- Angka porsi dibulatkan maksimal dua angka desimal dan mengikuti locale, misalnya `5.432343` menjadi `5,43` dalam bahasa Indonesia dan `5.43` dalam bahasa Inggris.
- Seluruh 331 string konten seed yang dirender pada Food Finder, Toxic Checker, porsi, dan resep diaudit; hasil bahasa Inggris tidak menyisakan token Indonesia yang terdeteksi.
- Toxic Checker hanya memberi verdict untuk nama bahan yang cocok tepat. Pencarian sebagian tidak lagi dianggap sebagai hasil keamanan final.
- Gambar burung yang gagal dimuat kembali ke emoji.
- Query publik memiliki filter eksplisit `is_active = true` dan `content_status = published`, termasuk saat browser sedang memiliki sesi admin.
- Cache konten dinaikkan ke versi baru agar cache lama tidak mempertahankan hasil sebelum perbaikan.
- Halaman error server memiliki teks Indonesia dan Inggris serta memilih bahasa dari header/browser atau preferensi tersimpan.
- Judul, description, Open Graph, dan atribut `lang` mengikuti bahasa publik tanpa menimpa metadata halaman admin.

## Perbaikan CMS admin

- Operasi data baru memakai `insert`; data lama memakai `update` yang ditargetkan dengan ID; delete memverifikasi bahwa baris benar-benar terhapus.
- Penyimpanan resep memiliki snapshot dan upaya rollback bila penyimpanan bahan atau langkah gagal.
- Respons AI yang terlambat diabaikan setelah admin berpindah entitas, memilih record lain, mengedit form, menyimpan, atau mengunggah gambar.
- Tombol dan field dikunci saat save, refresh, atau upload berlangsung untuk mencegah overwrite akibat operasi bersamaan.
- Form baru dapat membentuk ID/slug otomatis. Aturan porsi membentuk slug dari burung, ukuran, dan kondisi.
- ID record lama tidak dapat diubah dari form.
- Required field divalidasi setelah trim; array bahan/langkah tidak boleh kosong; urutan harus bilangan bulat nonnegatif; gram harus positif dan maksimal dua desimal.
- Saran gram dari AI juga dinormalisasi maksimal dua desimal di frontend dan Edge Function.
- URL gambar hanya menerima URL HTTP(S) valid atau path lokal; sumber hanya menerima URL HTTP(S) valid.
- Upload hanya menerima PNG, JPEG, atau WebP, menolak file kosong, dan membatasi ukuran 6 MB.
- Role reviewer tetap read-only dan hanya boleh menjalankan AI review.
- Error saat membaca profil admin dibedakan dari akun yang memang belum terdaftar di `admin_users`.
- Source JavaScript hasil kompilasi yang menduplikasi TypeScript dihapus agar Vite, editor, typecheck, dan runtime memakai satu source yang sama.

## Hasil pengujian

Lulus:

- `npm run typecheck`
- `npm run lint`
- `npm run format:check`
- Resolusi seluruh import source TypeScript/TSX
- 152 key bahasa Indonesia dan 152 key bahasa Inggris: tidak ada key hilang, tidak dikenal, atau tidak dipakai
- 331 string konten seed: tidak ada token Indonesia yang terdeteksi pada hasil bahasa Inggris
- SSR mock: halaman home, dashboard burung, dan initial state admin
- Mock Supabase: filter publik, insert, targeted update, verified delete, validasi upload
- Pemindaian secret: tidak ada `.env.local`, API key, atau service-role key di project hasil

Belum dapat dijalankan di sandbox:

- `npm run build`, karena `node_modules` dari ZIP awal berisi native binding Rolldown Windows, sedangkan sandbox memakai Linux. Arsip hasil tidak menyertakan `node_modules`.
- E2E terhadap Supabase produksi, login admin asli, policy RLS live, Storage live, dan panggilan Gemini live.

## Verifikasi terakhir pada mesin tujuan

Gunakan instalasi dependency bersih sesuai sistem operasi:

```bash
npm install
npm run qa
```

Kemudian jalankan di Supabase SQL Editor:

```text
supabase/verify.sql
supabase/verify_cms_ai_requests.sql
```

Uji manual terakhir sebaiknya mencakup login owner/editor/reviewer, create-edit-delete setiap entitas, upload gambar, publish/draft visibility, request burung, pergantian bahasa, dan Edge Function AI.
