PetBites Stronger Forest Background

Patch ini bikin background hutan lebih jelas lagi.

Cara pasang:
1. Extract zip ini.
2. Robocopy ke project:
   robocopy "D:\data C\Download\petbites_stronger_forest_bg" "D:\data C\Download\petbites" /E /R:1 /W:1
3. Jalankan ulang npm run dev.
4. Hard refresh browser: Ctrl + F5.
